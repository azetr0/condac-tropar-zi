# Troparul și condacul zilei – texte

Textele folosite de aplicația Android „Strana”: troparele și condacele sfinților, pe zi și lună (fără an), troparele Învierii și troparele Născătoarei de Dumnezeu de la sfârșitul Mineiului, pe cele opt glasuri.

Sursa fiecărui text este trecută în fișier, în câmpul `sursa`.
